# Instagram 投稿フォーマット集

音楽メディア／カルチャーメディア向けの、Instagram多スライド投稿のテンプレートと実例。
各型はテンプレート（記入用）と実例（記入見本）のセットで構成されている。

収録している型:
1. 多スライド特集（イベント／フェスティバル紹介）
2. 1枚完結投稿（地域ガイド・リスト系）
3. リリース紹介（音源フィーチャー）
4. キャンペーン投稿（チケットプレゼント等）
5. 月間ガイド（シーズン特集）

---

## 共通ルール

### スライド設計の原則
- 各スライドに役割を1つだけ持たせる。同じ情報を複数スライドで繰り返さない
- 構造（どの要素をどのスライドで立てるか）を決めてから本文を書く
- 詳細はスライドに任せ、キャプションは核の凝縮に徹する

### 文字数の目安
| 要素 | 目安 |
|---|---|
| キャッチコピー（2行） | 各行30文字以内 |
| 「〜とは?」解説スライド | 約160字 / 2段落 |
| 会場・音楽・体験スライド | 160〜200字程度 |
| キャプション | 200〜300字程度 |

### バイリンガル運用
- 日本語と英語は独立して書く。直訳しない
- 同じ内容・トーンを保ちつつ、それぞれの言語で最適化する
- 固有の文脈（地名・祭り・文化背景）は、海外読者に伝わるよう必要に応じて補う

### 表記ルール
- `——`（全角ダッシュ）は日英とも使わない。句点・読点・改行で対応
- 英語コピーに `ー`（長音符）を使わない
- 固有名詞は公式表記に準拠（大文字小文字も含む）

# 型1: 多スライド特集

イベント／フェスティバルの紹介。最も基本となる型。
規模に応じて6〜11枚。情報量が少ない場合は3〜4枚に縮小してよい。

## 標準構成

| スライド | 役割 |
|---|---|
| 1 | TOP（ビジュアル+基本情報） |
| 2 | キャッチコピー2行 |
| 3 | 「〜とは?」（背景・コンセプト） |
| 4 | 会場 |
| 5 | MUSIC（ラインナップ） |
| 6 | キャプション（投稿文） |

**拡張する場合の追加スライド**: SOUND（音響）／ART（アート・空間演出）／STAY（滞在・体験）／特別な文脈（提携イベント・地域の祭りなど）

## Slide 1: TOP

### テンプレート
```
上部左: {年} >> {月.日}
上部中央: {カテゴリ: FESTIVAL / PARTY / RAVE}
上部右: {地域}{カテゴリ}

中央上: \{キーワード}/
中央: {イベント名}
中央下: {会場名}, {地域}
       {国 or 開催時間}

下部: {メディア名}
```

### 実例
```
上部左: 2026 >> 07.17 - 20
上部中央: FESTIVAL
上部右: JAPAN FESTIVAL

中央上: \A PEAK EXPERIENCE/
中央: rural
中央下: nowhere CAMP, INAWASHIRO
       FUKUSHIMA

下部: Techno Japan
```

**ポイント**
- 中央上のキーワードは、そのイベントの唯一無二性を一言で表すもの。公式スローガンがあればそれを使う
- 会場が非公開の場合は `SOMEWHERE IN {地域}` のように、その秘密性自体をフックにする

## Slide 2: キャッチコピー2行

### テンプレート
```
🇯🇵
{場所・会場の特徴}で、{体験の核}な{期間}。
{音楽性 or コンセプト}が{動詞}、{イベントの性格}。

🌐
{English line 1}
{English line 2}
```

### 実例
```
🇯🇵
福島・猪苗代の高原で、音楽と自然に浸る4日間。
世界最高峰の音響と自然が響き合う、日本を代表する野外フェス。

🌐
A four-day experience woven slowly, in the highlands of Inawashiro, Fukushima.
One of Japan's defining open-air festivals, where world-class sound meets nature.
```

**ポイント**
- 1行目に「場所+体験」、2行目に「音楽性+立ち位置」を置くと安定する
- 各行30文字以内。オーバーしたら修飾を削る
- 抽象的な言葉より、読者が情景を思い浮かべられる具体を優先する

## Slide 3: 「〜とは?」

### テンプレート
```
🇯🇵
**{イベント名}**

{一言での定義}。
{始まりの年 / 歴史 / 主催者}。{そのイベントの核となる哲学やコンセプト}。

{今年ならではの変化・テーマ}。{具体的な内容}。

🌐
**{Event Name}**

{English paragraph 1}

{English paragraph 2}
```

### 実例
```
🇯🇵
**rural**

日本を代表する、長く続く野外フェスティバル。
電子音楽を主体に、その場に流れる時間そのものを設計する。ダンスミュージックを「鳴らす場」ではなく、時間をかけて編み上げられていく体験の場として、ruralは「A Peak Experience」を一貫して掲げてきた。

今年のruralは、3つの文脈がひとつの流れとして接続されるように設計されている。欧州文化の深層で蠢く実験性、アジア圏で脈動する解き放たれた感性、そして日本各地に点在する土着的なローカルシーン。テクノ、ハウス、アンビエント、実験音楽が、猪苗代の自然の中で交差する。
```

**ポイント**
- 段落1で「何者か」、段落2で「今年は何が違うか」を立てると構造が明快になる
- 主催者の言葉が強い場合は、編集で上書きせず原文の語彙と論理を活かす
- 約160字 / 2段落が目安

## Slide 4: 会場

### テンプレート
```
🇯🇵
**{会場名}**
{地域}, {国}

{会場の立地・地理的特徴}。
{その場所が持つ意味・歴史・環境}。

{会場ならではの体験・設備・特色}。{そこでしか得られない価値を締めの一文で}。

🌐
**{Venue Name}**
{Region}, {Country}
...
```

### 実例
```
🇯🇵
**nowhere CAMP**
Inawashiro, Fukushima

福島県猪苗代、沼尻高原に広がる前坂キャンプ場。ruralの舞台となって、今年で3年目を迎える。
日本百名山・安達太良山の麓、山々と湖に抱かれた日本有数の温泉地域であり、都市の時間軸から切り離された場所だ。

都市でもクラブでもない、この猪苗代の環境において、音楽、アート、自然、人がそれぞれの距離で交わっていく。この場にしか存在しない時間を紡いでいく。
```

**ポイント**
- 会場そのものが体験の核となるイベント（キャンプ場・温泉地・特殊空間）では厚めに書く
- 会場情報が薄い場合はこのスライドを省略し、他スライドに畳んでよい

## Slide 5: MUSIC

### テンプレート A（全体傾向+代表名）
```
🇯🇵
**MUSIC**

{音楽性・ジャンル}。
{ラインナップ全体の特徴・規模}。

{ヘッドライナー / 注目アーティストの紹介、1人1文}。
{その他の出演者を概要でまとめる}。

🌐
**MUSIC**
...
```

### テンプレート B（全員列挙）
```
🇯🇵
**MUSIC**

{ラインナップ全体の性格を表す一文}。

{アーティスト名を A to Z で列挙}

{時間の流れ・体験としてどう繋がるか}。

🌐
**MUSIC**
...
```

### 実例（テンプレートA）
```
🇯🇵
**MUSIC**

今年のruralには、それぞれの土地で培われた感覚を携えたアーティストが集う。
軸となるのは、3組の初来日。UKアンダーグラウンドの重要人物Al Wootton、Bristolの実験集団Giant Swanの一員RS Tangent、そしてウクライナ出身のVolodymyr Gnatenko。

海外勢の顔ぶれも濃い。ジョージアの名門〈BASSIANI〉の番人NDRX、ムンバイのアンダーグラウンドを牽引するChhabb、台北を拠点に独自の審美眼で活動するYuY。欧州からアジアまで、各地のシーンがruralのフロアで交差する。
```

### 実例（テンプレートB）
```
🇯🇵
**MUSIC**

秋田のローカルシーンと、国内外で活動するアーティストが、日本庭園のフロアにひと晩だけ集う。

arow, DJ Chris Hale, DJ SHINTARO, EICHI ABE, Garcir, Hikaru, irlsDot, Naoki Ikawa, starRo, squall

10組がバトンをつなぐように、21時から翌朝8時まで、途切れることなく音を重ねていく。
夜が深まり、やがて庭園に朝日が差し込むまで、電子音楽が鳴り続ける一夜。
```

**ポイント**
- テンプレートA: ヘッドライナーが明確な場合。序列を立てて紹介する
- テンプレートB: フラットなコミュニティ性を出したい場合。DIY寄りのイベントに合う
- 出演者が多い場合、全員を平板に並べるより核となるアーティストを立てて全体像を示す
- ラインナップが極端に多い場合は MUSIC を2〜3枚に分割してよい（例: 海外勢／B2B／国内勢）

## 最終スライド: キャプション（投稿文）

### テンプレート
```
🇯🇵
{イベント名} | {キャッチコピー1行目}

{イベントの定義・コンセプト}。{イベント名}が、{日付}から{期間}、{会場}で開催される。

{会場や体験の魅力}。

{ラインナップの核}。{全体像}。

{締めの一文。そのイベントの本質を突く}。

🎫 {チケット情報}
{誘導先}

⸻
◯ Dates / 日程 {日付}
◯ Venue / 会場 {会場}, {地域}

🌐
{English version}
```

### 実例
```
🇯🇵
rural 2026 | 福島・猪苗代の高原で、音楽と自然に浸る4日間。

「A Peak Experience」を掲げ、電子音楽を主体に時間そのものを設計してきた、日本を代表する野外フェスティバル「rural」。
7月17日から4日間、日本百名山・安達太良山の麓、温泉地に抱かれたnowhere CAMPで開催される。

今年は、欧州の実験性、アジアの感性、日本各地のローカルシーンが、ひとつの流れとして接続される。
Al Wootton、RS Tangent、Volodymyr Gnatenkoの初来日に加え、7年ぶり共演のWillikens & Ivkovicをはじめとする稀有なB2Bセットが揃う。世界最高峰のサウンドシステム〈Void Acoustics Incubus〉が、猪苗代の自然にその音を響かせる。

音楽、アート、自然、人が、それぞれの距離で交わる。
都市でもクラブでもない、この場所にしかない時間がここにある。

🎫 チケット → ZAIKO / RA（プロフィールのリンクから）

⸻
◯ Dates / 日程 2026.07.17 (Fri) - 20 (Mon)
◯ Venue / 会場 nowhere CAMP, Inawashiro, Fukushima
```

**ポイント**
- 1行目は `{イベント名} | {特徴を表す一文}` の形式で固定
- 各スライドで詳述した内容は繰り返さず、核だけを凝縮する
- 締めの一文でそのイベントの本質を突く。決め台詞を狙いすぎて空疎にならないよう注意

# 型2: 1枚完結投稿（地域ガイド・リスト系）

複数の店舗・スポット・イベントをまとめて紹介する型。スライドは不要またはビジュアル1枚のみ。

### テンプレート
```
{タイトル: A Complete {ジャンル} Guide to {対象} in {地域} {年}}{絵文字}

{対象の多様性を列挙した一文}、
{もう一段の列挙}。

{その地域の特性を立てる一文}、
{なぜこのまとめに意味があるかを伝える締め}。

⸻

{English version of the above}

1. {名称} {@ハンドル}
2. {名称} {@ハンドル}
...

By {メディア名}
```

### 実例
```
A Complete Music Guide to Clubs, Bars & Beats in EAST TOKYO 2026💫

新世代のクラブから音響にこだわるミュージックバー、
レコードとともに夜が回る小箱、DJと客の距離が近いフロアまで。

渋谷でも新宿でもない、
東京の東側に静かに育ってきた独自のクラブカルチャーを巡る完全ガイド。

⸻

From new-generation clubs to music bars built around sound,
small rooms where the night turns with the records,
and floors where DJs and dancers stand close.

Your complete guide to club culture growing quietly on Tokyo's east side, outside of Shibuya and Shinjuku.

1. Dungeon Akihabara @dungeon_akihabara
2. OUTPUT @music_bar_output
3. c6o Tokyo @c6o_tokyo
...

By Techno Japan
```

**ポイント**
- ヘッダーは「4要素の列挙 → 地域性で締める」構造が安定する
- タイトルはキャッチーな地域名を使い、本文ではより正確な範囲を示してもよい（例: タイトル `EAST TOKYO` / 本文「東京の東側」）
- リストは番号+名称+ハンドルのみ。各項目の説明は入れない

# 型3: リリース紹介（音源フィーチャー）

新譜・楽曲をフィーチャーするシリーズ投稿。

### テンプレート
```
FEATURE | {シリーズ名}
{アーティスト名}『{タイトル}』

{メディア名}の{シリーズ名}、第{N}弾。
{作品の位置づけを一文で}。

{制作の背景・きっかけ・レーベル情報}。

{サウンドの特徴を具体的に}。
{音楽的な文脈や系譜を、事実の範囲で}。

{印象を凝縮した短い一文}。
{読者への誘い}。

Writing by {ライター名}

⸻

{English version}
```

### 実例
```
FEATURE | PICK UP RELEASE
Tobias. × Doltz.『Frontiers of Science』

Techno JapanのPICK UP RELEASE、第1弾。
日本のモジュラーアーティストDoltzと、ベルリンの重鎮Tobias.による2作目のコラボレーション作『Frontiers of Science』を紹介。

きっかけは2024年、Eden Festivalでの偶然の出会い。そこから生まれた1作目『Versus』に続き、今作もオランダの名門Delsin Recordsからリリースされた。

全編を貫くのは、計算し尽くされた緻密さと、アナログ機材が放つ有機的な生命力の融合。
00年代初頭のclicks ＆ cutsの実験精神を受け継ぎながら、音の一つ一つが顕微鏡で覗いた細胞のように鮮明なエッジを持って迫りくる。理知的で、深淵。

2人の探究者が新たなフロンティアへと踏み込んだ一枚を、ぜひ。

Writing by Masafumi Take
```

**ポイント**
- シリーズ名は英語のまま日本語文中でも使う
- クリエイティブ側に詳細な楽曲解説を載せる場合、キャプションでは重複を避けて背景情報を補う
- ライタークレジットを明示すると専門性が伝わる

# 型4: キャンペーン投稿（チケットプレゼント等）

### 構成（4スライド）

| スライド | 役割 |
|---|---|
| 1 | TOP（賞品を明示） |
| 2 | 何が当たるか+イベント紹介 |
| 3 | 参加条件 |
| 4 | キャプション |

### Slide 1: TOP テンプレート
```
上部左: GIVEAWAY
上部中央: {メディア名} × {イベント名}
上部右: TICKET CAMPAIGN

中央上: \{当選数} × {賞品数}/
中央: TICKET GIVEAWAY
中央下: {イベント名}
       {開催地}

下部: {メディア名}
```

### Slide 3: 参加条件 テンプレート
```
🇯🇵
**HOW TO ENTER**

1. {アカウント1} と {アカウント2} のアカウントをフォロー
2. この投稿にいいね
3. コメントに友達をタグ付け
4. ストーリーでシェアしてチャンスを最大化

**抽選日**
{日付}

当選者にはDMでご連絡いたします。

🌐
**HOW TO ENTER**
...
```

### キャプション テンプレート
```
🇯🇵
TICKET GIVEAWAY | {イベント名} のチケットを{当選数}にプレゼント。

{イベントの魅力を一文で}。
{メディア名}から{当選数}に、{イベント名}のチケットをプレゼント。

【参加条件】
{条件を箇条書き}

【抽選日】
{日付}

{イベントへの期待を込めた締めの一文}。

⸻
◯ {イベント名}
{日付}
{会場}
{@公式アカウント}
```

**ポイント**
- 当選数と賞品数は視覚的に明快に（例: `1 WINNER × 2 TICKETS`）
- 参加条件はスライドとキャプションの両方に載せる（スライドを開かなくても参加できるように）
- メイン特集投稿とは日程をずらして投稿すると、認知の重ね打ちができる

# 型5: 月間ガイド（シーズン特集）

その月・シーズンのイベントをまとめて紹介する定期シリーズ。

### テンプレート
```
{ガイド名} {年}｜{月}
- {シーズンを表す言葉} -

{季節の状況を一文で}。
{その期間の特性}。{なぜこの時期が特別か}。

{ピックアップの趣旨}。

—

{English version}

—

{月}

1. {イベント名} {@ハンドル} 📅 {日程} | {会場}, {地域}
2. ...

By {メディア名}
```

### 実例
```
Japan Festival & Rave Guide 2026｜Jul - Aug
- THE SEASON BURNS -

夏が最も濃くなる季節。
7月から8月にかけては、イベントの数こそ落ち着くが、一つひとつが強い世界観を持つ。真夏の太陽の下でも、各地で個性際立つパーティが立ち上がる。

真夏の野外フェス・レイブから、いま体験すべきものをピックアップ。

—

The height of summer, when the season runs deepest.
From July into August, the events grow fewer, but each carries a world of its own. Beneath the midsummer sun, parties with striking character rise across Japan.

Here are the midsummer open-air festivals and raves worth experiencing now.

—

JUL - AUG

1. MOMENT @moment_jp 📅 07.03 > 07.05 | Dorogawa Camp, NARA
2. ORBIT @orbit_japan 📅 07.11 > 07.12 | Maesaka Camp, FUKUI
...

By Techno Japan
```

**ポイント**
- シーズンを表す言葉をシリーズ化すると継続感が出る（例: THE SEASON BEGINS → BURNS → PEAKS → GLOWS）
- 季節の状況は事実に基づいて書く。イベント数が少ない時期を「ハイシーズン」と書かない
- 各イベントは名称+ハンドル+日程+会場のみ。説明は入れない
