# 記事本文（BODY）でできること — 一覧（2026-10-10 時点）

CMS の記事編集画面（本文エディタ）で使える機能と、公開時に自動で起きることをまとめた。
**同じ内容は CMS の本文ツールバー「？ 使い方」からも見られる**（検索で絞り込み、「この機能を使う」でそのまま開く）。
CMS 側の文は `LP/cms.js` の `ARTICLE_BODY_HELP` にある。機能を足したら、この文書とそちらの両方を直す。
書き方のルールは [Techno_Japan_Web_Style_Guide.md](Techno_Japan_Web_Style_Guide.md) §8、ブロックの設計は
[../design/ARTICLE_BLOCKS_2026-10-09.md](../design/ARTICLE_BLOCKS_2026-10-09.md)。

## 1. 文字の装飾（ツールバー）

| できること | 操作 | 補足 |
|---|---|---|
| 見出し | H2 / H3 / H4 | H2 は大見出し（下に赤い線の演出）、H3 は小見出し、H4 は英字の小さなラベル。日本語の折り返しは文節単位（文字の途中で折れない） |
| 書体 | 標準 / Bebas（英字の見出し風・大文字化）/ Mono / Serif / Condensed | 文字単位で変えられる。日本語は Bebas にならない（英字専用の書体） |
| 大きさ | 小 / 標準 / 大 / 特大 | |
| 太字・斜体・下線 | B / I / U | |
| 引用 | 「引用」ボタン | 中央寄せ・細字・上下に赤い線。**他人の言葉**を引くときに使う。段落ごとに線が付くので、長い引用は1段落にまとめる |
| 揃え | 左 / 中央 / 右 | |
| 箇条書き | 番号付き / 点 | |
| リンク | 🔗 | 外部サイトへ。サイト内のフェス・アーティスト・会場へは下の「＠ ID」の方が楽 |
| 装飾を外す | 消しゴム | |
| 行内で改行 | Shift + Enter | 段落を分けずに改行する（住所や歌詞など） |

## 2. 画像

| できること | 操作 | 補足 |
|---|---|---|
| 画像を入れる | ツールバーの画像ボタン、またはドラッグ＆ドロップ／ペースト | 入れた瞬間に端末側で webp に変換・縮小される（原寸のまま上がることはない） |
| 幅を選ぶ | 画像をクリック → 「レイアウト」: 中央・標準 / 左寄せ（2/3）/ 右寄せ（2/3）/ 全幅 / 小さめ | 「全幅」だけ画面端まで広がる |
| 切り抜く | 「トリミング」: なし / 16:10 / 4:3 / 1:1 ＋ 拡大率・位置（横・縦） | 人物の顔が切れるときは位置を動かす |
| 2枚並べる | 画像を選んで「2枚セット（50:50）」 | 隣の画像と横並びになる |
| alt（説明文） | 英語版は「✨ 英語altを一括生成」 | 日本語の alt は画像ごとに入力 |

公開時に自動で: 画面幅ごとの派生画像（srcset）、幅・高さの属性（表示のガタつき防止）、遅延読み込み、スクロールで現れる演出、FIG.01 のような図版番号。

## 3. ブロック（本文に1行書くと、公開時にまとまった部品になる）

| ブロック | 入れ方 | 公開ページでの見た目 |
|---|---|---|
| **イベントカード** | 「📦 イベントカード」→ フォーム入力 → `[[event\|名前\|日程\|場所\|URL\|出演者\|補足\|フェスID]]` | 日程・名前・場所・LINEUP・公式リンク。フェスIDを選ぶと写真と最新 LINEUP が自動で入り、フェス詳細へリンク |
| **開催カレンダー** | 「📅 カレンダーを挿入」→ `[[calendar]]`（`[[calendar\|2026-12〜2027-02]]` で月を絞れる） | その記事のイベントカードを月ごとに自動で一覧化。カードが0件だとエラー |
| **アーティストカード** | 「＠ ID」→ アーティストを検索 → 行の右の「▣ カード」→ `[[artist-card:dj-nobu]]`（`\|一言` を足せる） | 写真・名前・ジャンル・拠点・経歴の冒頭・SNS。中身はスプレッドシート ARTISTS から。一言を書くと経歴の代わりに出る |
| **プルクオート** | 文を選択して「❝ プルクオート」→ `[[pullquote\|本文\|出典]]` | 本文の一文を中央・大きめ・上下赤線で見せる。出典は任意。**自分の本文**を抜き出すときに使う（他人の言葉は「引用」） |

ブロックは JS 不要の静的 HTML になる。存在しない ID を書くと公開（ビルド）が止まるので、下書きのうちにプレビューで確かめる。

## 4. サイト内リンク

| できること | 操作 | 補足 |
|---|---|---|
| フェス・アーティスト・会場・記事へリンク | 「＠ ID」または本文で `@` を打つ → 名前で検索 | 文中に名前入りのリンクが入る |
| アーティスト名の自動リンク | 何もしない | 公開時に、本文中のアーティスト名（ARTISTS に登録済み、3文字以上）が自動でアーティストページへリンクされる。誤爆しやすい一般語は除外リストあり |

## 5. 書くのを助ける機能

| 機能 | 操作 |
|---|---|
| 雛形 | 「📄 テンプレ」: イベントレポート / インタビュー / ニュース / 週間まとめ / フェスまとめ / コラム |
| 集中モード | 「⛶ 集中モード」または ⌘⇧F。全画面で執筆、プレビューは右に固定できる |
| プレビュー | 「プレビュー」（横に並べて即時反映）と「↗ 本番表示」（本番と同じ CSS/JS で別画面） |
| HTML を直接編集 | 「HTML」タブ |
| 編集履歴 | 「📜 履歴」 |
| 保存 | ⌘S。入力中の値は閉じて開き直しても保持される |
| 読了時間 | 本文の長さから自動計算（手で入れた値があれば上書きしない） |
| 見出し候補・翻訳 | AI でタイトル案、各欄の翻訳、本文全体の英訳 |

## 6. 英語版

「🌐 ENGLISH VERSION」に英語の本文・タイトル・要約を入れると `/en/articles/...` に英語ページが出る。
ブロック（`[[event]]` `[[artist-card]]` `[[pullquote]]`）は英語本文でも同じ書き方で、見出し語（LINEUP / ARTIST PAGE 等）と
アーティストの経歴が英語になる。英語本文が無い記事は、英語ページも日本語本文のまま。

## 7. 公開時に自動で起きること（本文から作られるもの）

- 要約（EXCERPT）が空なら本文の冒頭 160 字が検索結果用の説明文になる
- 文字数から読了時間、本文のイベントカードから検索エンジン向けの Event 構造化データ
- 関連記事、シェアボタン、ニュース一覧へ戻るリンク、JA/EN の切り替え
- 読み進めた量のバー、見出し・画像・ブロックがスクロールで現れる演出（動きを減らす設定の端末では止まる）

## 8. まだ無いもの

| 欲しくなりそうなもの | 状態 |
|---|---|
| 折りたたみ（開閉できる補足） | 未実装。設計済み（`[[details\|見出し]] … [[/details]]`）。指示があれば着手 |
| 表 | 未実装。設計済み（`[[table\|…]]`）。使う記事が出てから |
| 動画の埋め込み | ボタン無し。HTML タブで `<iframe>` を書けば YouTube は表示できる（CSP で許可済み）が、公式の手順ではない |
| 脚注・目次 | 無し |
