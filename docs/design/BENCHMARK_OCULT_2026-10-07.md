### Ocult の型（何が「洗練」を作っているか）
1. **カードの解剖が1種類**: 写真（16:9）／赤いカテゴリ札（等幅）／日付（右寄せ）／下線付き見出し／（大カードだけ）2行の要約。TOP の全ブロックがこの1種類の繰り返し。
2. **見出し＝リンク**: 「The latest in music →」の矢印が示すとおり、セクション名を押すとハブへ行く。「VIEW ALL」を別に置かない。
3. **写真は2段階だけ**: 全幅か、半分×2。中途半端な幅が無いので、スクロールのリズムが読める。
4. **記事の頭が3行で決まる**: 見出し → デッキ（主張）→ カテゴリ・筆者・日付の1行。写真はその後。
5. **末尾が厚い**: 1本読み終えた人に、関連3枚・前後・おすすめ・カテゴリ格子と、4段階で次を差し出す。
6. **一番上に赤い1行**: 「MUSIC｜Asia Music Event… Read Now」。いま一番押したい1本を、全ページの最上段に1行で。

### Techno Japan が既に持っていて、Ocult に無いもの（残す）
- **UPCOMING EVENTS**（日付・会場・出演者つきの開催予定）。Ocult は「The weekend guide」枠が空のまま（埋め込みが読み込まれていない）。TJ の最も固有な資産。
- 黒の世界観、Bebas Neue の見出し、FIG 索引、ARTISTS / VENUES のデータベース。
- 日英切替。

### 取らないもの
明るい地色、物販、コメント欄、2段のメガナビ、Inter。TJ の識別性を落とす。

## 2. 設計（黒のまま、構成だけ Ocult に寄せる）

### WP-A 記事の頭と写真幅（最優先。流入の大半は記事に着地する）
- **見出しを写真の上から外し、写真の前に置く。** 写真の上に重ねた 34px（スマホ）は、写真が明るいと読めない。
  順番: カテゴリ札 → 見出し（Bebas、PC 64 / スマホ 36）→ **デッキ**（excerpt を「段落」ではなく 20px 太字の1文として置く）→ 1行署名（既存の `.article-specs` 1行版）→ 全幅写真 → キャプション1行。
- **写真幅を2種に絞る**: 全幅（本文幅 680 を超えて 1100 まで抜く）と 50/50 の2枚組。現在の 93 / 52 / 34 は廃止。
  `article-fx.js` の `figIndex % 3` のリズムを「全幅 → 2枚組 → 全幅」に変える。縦位置の写真は 2枚組へ回す（横長≥1.9 の fx-bleed は残す）。
- 本文 PC 17 → 18px。スマホ 16 のまま。キャプション 10 → 12px。
- **excerpt と本文1段落目が同一なら本文側を描かない**（ONDO LAND 記事で2回出ている。公開15本中1本だが、ガードは生成側に入れる）。

### WP-B TOP の1画面目（写真が先、宣言は後）
- 宣言文 52px の塊を **1行の eyebrow**（「JAPAN / UNDERGROUND DANCE MUSIC / MEDIA」の行に吸収）に縮め、**最新2本を 49% 幅の写真2枚**で置く。見出し・札・日付・2行要約つき。
- その下に **「LATEST →」2×2**（見出し自体を news.html へのリンクに）。「VIEW ALL →」は消す。
- UPCOMING EVENTS は3番目に残す（TJ の固有資産）。ARTISTS / VENUES は1段ずつに圧縮。
- スマホ: 宣言文を 1行にし、**最初の写真を y<200 に**。
- 目標（同じ probe で前後比較）: 1画面目のリンク PC 6→20 以上・スマホ 3→8 以上、写真 1→6 以上。
- 判断: カテゴリ別ブロック（「FESTIVAL & RAVE →」「GUIDE →」）は記事が 9 / 3 / 2 / 1 本なので**まだ作らない**。1カテゴリ6本を超えたら追加。

### WP-C 記事の末尾（読み終えた人に4段階で次を出す）
- INFORMATION（h3＋段落）を **開催情報カード**に（日付・会場・チケット。既存の `tj-event` ブロックの型を流用）。
- RELATED STORIES をリスト行から **写真カード3枚**に（WP-B と同じカード）。
- **前の記事 / 次の記事** を追加（日付順。既存データで作れる）。
- **NEXT EVENTS 3件**（UPCOMING EVENTS の最初の3件）を記事末尾にも置く。Ocult の「おすすめ横スクロール」の代わりに、TJ にしか無いものを置く。
- 目標: 末尾30%のリンク 6→20 以上。

### WP-D カードの統一と最上段の1行
- 4ハブ＋TOP のカードを **1種類**に: 16:9 写真 / カテゴリ札（Space Mono）/ 日付 / 見出し（ホバーで下線）。
  現在は story-hero・story-row・event-row・artist-portrait・venue-tile の5種。ARTISTS（縦位置）と VENUES は別型のまま残してよいが、**記事系は1種**にする。
- **最上段に1行の告知バー**: 「NEXT  LABYRINTH  OCT 10–12  →」。UPCOMING の先頭を全ページの一番上に。閉じられる。

### 実装の順番と、やらない判断
A → B → C → D。A と C は `build-detail-pages.mjs` と `detail.css` / `article-fx.*`、B と D は `index.html` / `common.css`。
各 WP の前後を同じ probe で測って handoff に並べる（リンク数・写真数・最初の写真の y・本文幅）。
