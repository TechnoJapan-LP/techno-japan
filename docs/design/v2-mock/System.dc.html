03 Modules

  1. Hero overlay（記事・TOPリード・フェス詳細）：全幅写真 + 下からのグラデーション + cat-pill + Bebas見出し + サブ。現 .article-hero を共通化。
  2. Story card：写真（16:9 / 4:3）→ 赤メタ → Bebas見出し → サブ。3段の順番は固定。
  3. Related story（横長）：260px 16:9サムネ + 見出し。現 .related-story-card.is-wide を一覧の下部（リスト表示）にも流用。
  4. DB row：日付（Bebas大）/ 名前 / 場所 / 種別 / ステータス。Festivals・Venue詳細・Artist詳細で同一。
  5. Fact strip：6マスの等幅ラベル + 値。フェス詳細のDATE / LOCATION / PREF / GENRE / LINEUP / EDITIONS。
  6. Filter chips：等幅10px、選択中は赤枠。Season / Type / City / Genre / View。

04 Motion

  • マーキー（TOP上部）：40s linear、Bebas 18px。
  • 画像 hover：scale 1.04 / 0.7s。アーティストは grayscale → color。
  • 見出し hover：Ink → Accent soft。
  • 地図ピン：赤、2.4s pulse。背景のグリッドドリフト・スキャンラインは現サイトのまま維持（prefers-reduced-motion で停止）。

05 Data sync

このキャンバスの全ページは project/tj-data.js を読んで描画している。元データは本番と同じ LP/data（festivals / editions / artists / venues）と data.js の ARTICLES。更新手順：

cd ~/Developer/techno-japan
node .scratch/tj-design-sync/sync.mjs     # LP/data → design-data.json + img/
# → Claude に「同期して」と言えば画像の再アップロードと tj-data.js の差し替えまで行う

本実装では同じ構造（記事＝ARTICLES、DB＝festivals/editions/artists/venues/lineups）をそのまま使えるので、このモックは実装仕様書として Claude Code / Codex に渡せる。
